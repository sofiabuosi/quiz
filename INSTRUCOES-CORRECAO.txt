CORRECOES DO FEEDBACK - QUIZ AMIGOS

Este pacote contém os arquivos alterados, mantendo os caminhos relativos do projeto.
Extraia o conteúdo na raiz de ~/Documents/quiz/quiz e permita substituir os arquivos.

1. Confira que está na branch de correção:
   cd "$HOME/Documents/quiz/quiz"
   git branch --show-current

   O resultado esperado é: correcao-feedback

2. Extraia o pacote na raiz do projeto:
   unzip -o "$HOME/Downloads/quiz-correcao-feedback.zip" -d "$HOME/Documents/quiz/quiz"

3. Compile e execute os testes do plugin:
   cd "$HOME/Documents/quiz/quiz/plugins/quizamigos"
   ant clean test jar

   O alvo de testes inclui QuizBehaviorRulesTest e os testes anteriores.

4. Se a compilação e todos os testes terminarem com BUILD SUCCESSFUL, volte à raiz:
   cd "$HOME/Documents/quiz/quiz"
   git diff --check
   git status --short

5. Registre as alterações na branch de correção:
   git add build.xml src/ test/ plugins/quizamigos/build.xml \
       plugins/quizamigos/src/ plugins/quizamigos/test/
   git commit -m "Quiz: corrige entrada em partidas, respostas e histórico"
   git push -u origin correcao-feedback

6. Só depois de testar com pelo menos dois computadores, integre a correção à main:
   git switch main
   git merge --no-ff correcao-feedback
   git push origin main

ALTERACOES INCLUIDAS
- Uma pergunta de outro quiz não substitui uma partida que já está em andamento.
- Jogadores ociosos recebem um convite e precisam aceitar para entrar; convites recusados
  não reaparecem a cada pergunta.
- Participantes podem enviar respostas no modo anfitrião; o anfitrião não responde à
  própria pergunta. A comparação aceita os índices A, B, C e D (0 a 3).
- O histórico registra também jogadores com zero pontos, inclusive o jogador local.
- Falhas ao ler ou gravar o histórico deixam de ser silenciosas e aparecem na interface.
- Foram adicionados testes automatizados para essas regras.

OBSERVACAO
O histórico continua sendo local a cada computador, em ~/.pitiupi/quizamigos/history.properties.
Este pacote não transforma o histórico em um ranking central compartilhado pela rede.
A comunicação ainda usa broadcast; a proteção contra troca de partida ocorre na recepção,
com confirmação para entrar quando o computador está ocioso.
